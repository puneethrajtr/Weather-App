# 🌦️ Weather App (Weather_App_1)

## 📌 Project Overview

The **Weather App** is a web-based application that provides **real-time weather information** for any city entered by the user.

This project was developed as part of my learning and internship work to demonstrate **API integration, frontend development, and asynchronous JavaScript concepts**.

---

## 🚀 Features

* 🌍 Search weather by city name
* 🌡️ Display current temperature
* 💧 Show humidity levels
* 🌬️ Display wind speed
* ☁️ Show weather conditions (Cloudy, Clear, Rainy, etc.)
* ⚡ Real-time data fetching using API
* 🎨 Simple and clean user interface

---

## 🛠️ Tech Stack

* **HTML** – Structure
* **CSS** – Styling
* **JavaScript** – Logic and API handling
* **Weather API** – Fetch real-time data

## ⚙️ How It Works

1. User enters a **city name**
2. JavaScript sends a request to the **Weather API**
3. API returns real-time weather data
4. The data is displayed dynamically on the webpage
